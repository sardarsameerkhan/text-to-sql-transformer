# Text-to-SQL Transformer from Scratch

Implementation of an encoder-decoder Transformer from scratch using PyTorch for translating natural language questions into SQL queries on the WikiSQL dataset.

## Authors
- Team Member 1
- Team Member 2

## Project Structure
- `starter/`: Dataset loaders, preprocessors, tokenizer, and embedding definitions.
- `model/`: Attention mechanisms, Transformer layers, and full encoder-decoder model.
- `app/`: Web UI front-end interface.
- `results/`: Evaluation figures, metrics, and generated predictions.
